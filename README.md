# Portfólio — Arthur Correia Nunes

Portfólio profissional responsivo construído apenas com HTML5, CSS3 e JavaScript ES6. Não exige instalação, compilação ou servidor local.

## Executar

Abra o arquivo `index.html` diretamente em qualquer navegador moderno. Para melhor resultado, mantenha uma conexão com a internet: fontes, ícones, partículas e imagens são carregados por CDN/Unsplash.

## Editar conteúdo

- **Dados e seções:** edite `index.html`.
- **Cores, layout e responsividade:** edite `style.css`. As variáveis de cor ficam no início do arquivo.
- **Animações e comportamento:** edite `script.js`.
- **Currículo:** coloque seu PDF em `assets/pdf/curriculo-arthur-correia-nunes.pdf`. O botão de download já está configurado para esse caminho.
- **Links:** substitua os links genéricos de LinkedIn, GitHub e e-mail no `index.html` pelos seus endereços reais.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie todos os arquivos deste projeto.
2. Acesse **Settings → Pages** no repositório.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)`; depois salve.
5. Aguarde a URL pública disponibilizada pelo GitHub.

## Publicar na Vercel

1. Envie o projeto a um repositório GitHub.
2. Acesse [vercel.com](https://vercel.com), faça login e clique em **Add New → Project**.
3. Importe o repositório e mantenha as configurações padrão.
4. Clique em **Deploy**. Como é um site estático, não há configuração de build necessária.
